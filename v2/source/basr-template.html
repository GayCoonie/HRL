Added R/L layerBASR · global Q(L)

The base chart receives L₀ = Q(L), R₀ = Q(L)R/L. Thus max(linear RGB) = Q(L) and min(linear RGB) = Q(L)(1 − R/L). Q is inverse normalized CIE L*. Hue is solved on the unchanged observer sheet. This does not claim equal perceptual steps across all chromatic colors.

Full-domain provenance is unchanged: a 5 nm spectral/purple-boundary approximation and an observer-fitted continuation. Computational hue preservation is not the same as observer accuracy. The sRGB triangles use the actual sRGB cube, not a clipped or truncated full-domain rendering.
