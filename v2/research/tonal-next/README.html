HRL v2 tonal continuation — 19 September 2026

This additive experiment continues the frozen Beta 1 (metric-b2) shared tonal map. The release definition, source hue family, neutral progression, boundary and public default remain unchanged.

The question is whether a bounded continuation improves the difficult dark/high-Reach blue region while preserving observer-fit accuracy, path quality and the geometric contracts. The fit reuses COMBVD development data. Synthetic GenSpace path, sheet and conditioning penalties are not additional observer evidence.

Reproduce

Use Python 3.12 with torch 2.10.0 CPU, NumPy 2.3.5, SciPy 1.17.0 and Node 24.19.0 for the recorded environment. The inherited source-grid generator makes two approximately 82 MiB grids:

HUES=96 GRID=193 node v2/research/boundary-tonal/cache-grid.mjs

Move the generated gen-grid-srgb.f64, gen-grid-full.f64, and grid.json into a separate cache directory and restore the historical tracked boundary-tonal/results/grid.json. Pass that cache's absolute path through --gridroot. The new grid receipt is retained with this experiment; regenerated bytes need not match historical grids produced under a different runtime.

Run fit.py with the exact command recorded in RESEARCH.md. The current fitter refuses existing trial filenames. The archived fit-first-round.py reproduces the initial two trials; it predates that overwrite guard, so use a fresh output directory with it. Each candidate keeps its full coefficient arrays, code and input identities, objective statistics, and closure trace. The baseline guard now references Beta 1 itself, with explicit STRESS-point slack; the original fitter guarded the older 0.12 parent even when started from Beta 1.

test_guard_reference.py exercises a real zero-step fit; set HRL_GRIDROOT to the separate cache. The test first failed on the old parent identity, then passed after the new guard was installed. It checks emitted arrays, reference identity and exact observer scores; it does not independently test every penalty activation.

audit.mjs --out /absolute/new-receipt.json label=/absolute/record.json evaluates actual JavaScript forward/inverse behavior, retained native3331/full3813 COMBVD, separate mapped-native3813, all four direct path families, sheet bending, source hashes and sampled geometric contracts. It refuses existing receipt destinations. The normal72-hue aggregates stay separate from extra critical angles.

conditioning-audit.py --output /absolute/new-receipt.json --record label=/absolute/record.json compares the analytic common-coordinate Jacobian with autograd and actual JavaScript finite differences over several legal steps. It measures fixed-H common-map anisotropy, not the full XYZ or perceptual Jacobian. A separate high-precision independent reproduction is retained with the evidence.

Interpretation

The frozen research protocol and final comparison receipt define eligibility. COMBVD is fitted development data, not a held-out observer result. Native retained and full retained populations differ. Improved conditioning alone does not establish smoother displayed sheets. Screen previews clip to sRGB and cannot display the full physical-reference gamut.

The second-round fitter separates the121 historical sheet centres from20 extra edge centres. It can use raw or robust core bending while penalizing edge regressions separately. Exact exploratory pivots and settings are appended to the research record.

See RESULTS.md for executed outcomes and limitations, and results/comparison.json for the concise machine-readable comparison. Raw diagnostics, fit traces and independent review remain attached to the reproducibility packet.
