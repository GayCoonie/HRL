HRL — Hue, Reach, Level

A color space built around a regular hue bicone: black, white, and vivid in every equilateral hue triangle.

Current v2 release: HRL v2 Beta 1

The selected 0.13 metric-leaning checkpoint (metric-b2), now the v2 default. This is a promotion, not a new fit. One shared learned Reach/Level bank operates over native sRGB and the repaired full physical-reference domain.

Geometry and units

Public coordinates satisfy 0 <= R <= L <= 1; H is cyclic degrees. Shares are chromaticness R, whiteness L−R, and blackness 1−L. Level is inverse blackness, not a synonym for luminance.

The regular-bicone embedding is [L-R/2, sqrt(3)/2*R*cos(H), sqrt(3)/2*R*sin(H)], with H converted to radians inside the trigonometric functions. Distance is Euclidean in that embedding, not in raw H/R/L.

GitHub Pages and local use

The repository is served directly at https://gaycoonie.github.io/HRL/, from main at the repository root. The site is static; no account, framework, CDN, or backend is needed to use the pickers.

For local browser use, retain the full repository layout and serve it over HTTP:

git clone https://github.com/GayCoonie/HRL.git
cd HRL
python3 -m http.server 8000
# Open http://localhost:8000/v2/ for the current release.
# Open http://localhost:8000/ for Release 1.

The reference modules also work in Node 18 or later. The modular pickers need HTTP rather than a file: page; preserved standalone research viewers keep their embedded model data.
